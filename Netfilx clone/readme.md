🎬 Case Study: Netflix Clone – Frontend Project Using HTML & CSS
📌 Project Overview
The Netflix Clone is a frontend web application that replicates the user interface of the popular streaming platform Netflix. The aim of this project was to strengthen my skills in HTML and CSS, focusing on layout design, responsiveness, and modern UI practices without using JavaScript or backend functionality.

🎯 Objectives
Recreate the Netflix homepage UI with a responsive layout.

Practice working with HTML semantic tags and clean structure.

Build a visually appealing interface using only CSS.

Understand how media queries and flexbox/grid can make a design responsive.

🛠️ Tools & Technologies
HTML5 – Structuring the web content

CSS3 – Styling and layout

Google Fonts – For custom font styles

Font Awesome / Icons8 – For icons

VS Code – Code editor

GitHub Pages / Netlify – Deployment

💡 Features Implemented
✅ Netflix-style hero section with background image and overlay

✅ Navigation bar with logo and buttons (Sign In, Join Now)

✅ Responsive layout using Flexbox and Media Queries

✅ Subscription CTA section with input box

✅ Mobile-first design approach

✅ Clean and organized file structure

📱 Responsive Design
The layout was built to adapt to various screen sizes:

Desktop (1080p+)

Tablet (768px–1024px)

Mobile (≤768px)

This was achieved using flexbox, percentage widths, and media queries.

🧠 Challenges Faced
Creating an overlay over the hero background that still allowed readable text.

Aligning elements responsively without breaking the layout.

Matching Netflix's exact UI style with pure CSS (especially fonts, padding, spacing).

📈 What I Learned
Better understanding of CSS positioning, z-index, and layering

How to structure an HTML document semantically

How to deploy projects on Netlify and manage responsiveness
